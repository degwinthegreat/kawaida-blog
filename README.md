# Shinsuke Kawaida — personal site

Source for [kawaida-blog.vercel.app](https://kawaida-blog.vercel.app/). The site combines a concise professional profile with a small Markdown-based writing archive.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Writing

Add a Markdown file to `posts/` with `title` and `date` front matter. It will be included in the home-page writing list and generated under `/posts/<file-name>`.

## Checks

```bash
npm run lint
npm run build
```
